## Usage

Installed from the registry, import from `@/components/ui/switch`; inside this monorepo, from
`@rabtx/ui/switch`.

```tsx
import { Switch } from "@rabtx/ui/switch";

export function WifiSetting() {
  const [on, setOn] = useState(true);
  return (
    <Switch checked={on} onCheckedChange={setOn}>
      Wi-Fi
    </Switch>
  );
}
```

It is an `<input type="checkbox">` with `role="switch"` and the HTML `switch` attribute, so the
browser provides Space to toggle, the form value (`name`, `value`), and the on and off state for
screen readers. With children it wraps itself in a `<label>`, so the text names it and the whole row
toggles it. A bare switch needs a `Field` or an `aria-label`.

## Sizes

`sm` (36 by 20), `md` (48 by 28, the default) and `lg` (56 by 32). The small size keeps a 24px
click area.

The thumb starts on the inline start edge and travels toward the end, so it mirrors in

Radius follows `--radius-button` (a capsule in Default and Round, nearly square in Sharp). Flat
drops the recess on the track and the ring on the thumb. Motion off keeps every state but moves

## API

`Switch` takes everything a native checkbox `<input>` takes, except `type`, `size` and `role`,
plus:

<TypeTable
  type={{
    checked: { type: "boolean", description: "Controlled state." },
    defaultChecked: { type: "boolean", description: "Uncontrolled initial state." },
    onCheckedChange: { type: "(checked: boolean) => void", description: "The new state after every toggle." },
    size: { type: '"sm" | "md" | "lg"', default: '"md"' },
    disabled: { type: "boolean", description: "Dimmed, skipped by Tab, never toggles." },
    children: { type: "ReactNode", description: "A label. Wraps the switch in a <label>." },
    className: { type: "string", description: "On the label when there are children, otherwise on the switch." },
  }}
/>

Outside React, the class names are exported from `@rabtx/ui/switch/styles`:

```html
<label class="rx-switch-label">
  <input type="checkbox" role="switch" switch class="rx-switch rx-switch-md" />
  Wi-Fi
</label>
```

## Theming

The Switch reads only the [theme tokens](/docs/ui/theming).

| Part | Tokens |
| --- | --- |
| Track | off `--muted-foreground` (70% over `--background`), on `--primary` |
| Thumb | off `--background`, on `--primary-foreground` |
| Depth (Floating) | track `--field-edge-top`, `--field-edge-bottom`, `--field-shade`; thumb `--surface-ring`, `--surface-sheen`, `--surface-shade` |
| Focus and error | `--ring`, `--destructive` |
| Label | `--foreground`, disabled `--disabled-foreground` |
| Corners and motion | `--radius-button`, `--spring-switch`, `--motion-ease` |

## How the motion works

| Effect | CSS |
| --- | --- |
| Travel | `:checked` sets the thumb's `--_x` to the track width minus its height; `inset-inline-start` follows on the `switch` spring (stiffness 800, damping 80, mass 4: a heavy thumb, about 4% overshoot, settled in 527ms), solved into a `linear()` easing |
| Press | `:active` (on the switch or its label) widens the thumb by 4px toward where it is going (the near edge stays put) and scales it to 0.9, on the same spring |
| Release | the toggle moves `--_x` while the width and scale spring back, so the thumb lands as it un-squishes |
| Track | `--_fill` is a registered `@property` color, so the fill inside the gradient layers fades in 200ms |
| Right to left | the thumb is placed with `inset-inline-start` (which is what transitions), so it starts and travels from the inline start in either direction |

The thumb is the input's `::before`, so there is no extra markup to keep in sync.

## Browser support

- **Everywhere:** `appearance: none`, `:checked`, `:active`, `:has()`, `color-mix()`, logical insets,
  nesting, `@property` and `linear()` easings: Chrome 120+, Safari 17.2+ and Firefox 128+ draw the
  same switch (from compatibility data; tested in Chrome).
- **Safari 17.4+:** the `switch` attribute makes it a native switch (announced as on and off,
  `:indeterminate` never matches). The page's CSS still draws it. Elsewhere the attribute is
  ignored and `role="switch"` gives the same semantics.
- **Not used yet:** the experimental `::thumb` and `::track` pseudo-elements (Safari behind a flag).

## Accessibility

- Announced as a switch, on or off, from the input's native checked state; there is no
  `aria-checked` to drift.
- Space toggles it. Enter does not, as with any native checkbox.
- Focus shows a 2px `--ring` outline. Label it with children, a `Field` or an `aria-label`.
- The state is shown by position and color, never motion alone. Reduced motion and
  `data-motion="off"` switch instantly.
